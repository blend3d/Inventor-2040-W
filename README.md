# Inventor 2040 W
Pimoroni Inventor 2040 W based SMARS

<img width="914" height="676" alt="image" src="https://github.com/user-attachments/assets/2d10a307-fdc5-48c1-bb39-a497bb0f5824" />

For build details, see the “Inventor 2040 SMARS Build Guide” in the “Build and Part Info” folder. The “STL” folder contains all parts customized from the original SMARS design, plus two extras: a storage box and a programming stand. The stand holds SMARS off the desk while you work on code, so it can’t drive away mid-test.

The “Code” folder contains several MicroPython test and demo files, plus a basic “main.py” that lets SMARS avoid obstacles using a time-of-flight (ToF) sensor and timed turns. The “Inventor Function Cheatsheet” in the same folder is a handy reference for the Inventor 2040’s functions.

Planned improvements:
    
    PID-based motion control for more precise, predictable movemen
    OLED display for feedback
    LDRs for photovore (light-seeking) behavior

Ideas for extending SMARS:
    
    status indication using the onboard RGB LEDs
    PIR sensor to hide from or seek movement
    Microphone for noise-seeking or noise-avoiding behavior
    Small breadboard for experiments
    Remote control via web or mobile phone
    Anything else you can dream up!
