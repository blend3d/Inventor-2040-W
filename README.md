# Inventor 2040 W
Pimoroni Inventor 2040 W based SMARS

Simple code snippets at the moment as I work to have our SMARS navigating based on a TOF sensor. Eventually a display and photovore behavior will be added as well as wi-fi connectivity.

Idea List for add-ons:
    
    LDR or Phototransistor light seeking or avoiding behavior
    SSD1306 0.96" OLED display
    RGB LED status indication
    PIR sensor for hide or seek Behavior
    Microphone for noise seeking or avoiding behavior
    Small breadboard for experiments
    Remote control via web or mobile phone
    Web telemetry from SMARS
    ...and Whatever else comes to mind!
