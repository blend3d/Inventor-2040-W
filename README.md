# Inventor 2040 W
Pimoroni Inventor 2040 W based SMARS

<img width="914" height="676" alt="image" src="https://github.com/user-attachments/assets/2d10a307-fdc5-48c1-bb39-a497bb0f5824" />

There are some micropython files for test and demo along with a "main.py" program in the "Code" folder. The "main.py" file allows SMARS to navigate obstacles based on a TOF sensor. 
Eventually I would like to add an OLED display, and photovore behavior. 

Below are some ideas for adding additional functionality to SMARS in the future:
    
    RGB LED status indication
    PIR sensor for hide or seek Behavior
    Microphone for noise seeking or avoiding behavior
    Small breadboard for experiments
    Remote control via web or mobile phone
    And Whatever else comes to mind!

Please see the "Inventor 2040 SMARS Build Guide" in the "Build and Part Info" folder for additional info. Also reference the "Inventor Function Cheatsheet" in the "Code" folder. 
All STLs that were customized from the original SMARS are in the STL folder.

Enjoy!
